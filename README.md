Project Title: SETU-Speech Enabled Translation Utility

Objective:

Build an intelligent web application that bridges language barriers by combining Automatic Speech Recognition (ASR), Neural Machine Translation (NMT), and Text-to-Speech (TTS) technologies, delivering seamless, real-time voice-to-voice translation.


Target User Experience:

Users can speak in any of the 8 Supported Languages.
The system automatically detects the source language.
The user's speech is transcribed into text, translated into the Target Language, and converted back into natural-sounding speech in real-time.
The interface should be intuitive, offering options to select source/target languages and a clear visual feedback loop of the translation process.


Technical Requirements & AI Tools (Google Gemini API):
Language Support: English, Hindi, Spanish, French, Arabic, Russian, German, Chinese.


Voice Recognition (ASR): Convert spoken audio into text.


Translation (NMT): Translate text from source to target language.


Voice Generation (TTS): Convert translated text back into natural speech.


Real-time Processing: Ensure minimal latency (<2-3 seconds for the full cycle).
